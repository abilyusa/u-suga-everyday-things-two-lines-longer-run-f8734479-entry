A two-line explanation of a traffic jam for a 10-year-old: line 1 pictures the jam as a whole school squeezing out of one narrow door when the bell rings, line 2 says honestly what that picture maps and what it leaves out. Built by an AI agent for make.fun's “Everyday Things, Two Lines, Longer Run” bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes the two-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
